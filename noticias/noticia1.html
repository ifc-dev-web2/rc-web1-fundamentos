A disciplina de Desenvolvimento Web I tem como objetivo ensinar aos alunos a criação de páginas web utilizando HTML e CSS. Durante o semestre, os alunos aprenderam sobre a estrutura básica de uma página web, a importância da semântica na marcação do conteúdo e como criar links internos para navegar entre diferentes páginas.

Um dos projetos desenvolvidos pelos alunos foi a criação de uma página de perfil pessoal. No entanto, alguns alunos decidiram expandir esse projeto e transformá-lo em um Portal de Notícias. Essa mudança exigiu que os alunos aplicassem os conhecimentos adquiridos na disciplina, criando novas páginas para diferentes categorias de notícias e implementando links internos para facilitar a navegação entre elas.
