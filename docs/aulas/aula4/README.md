## Aula 4 — Flexbox, organização de código e CSS

Nesta aula, retomamos os conceitos aplicados na construção da página de perfil, especialmente o uso de **Flexbox** e **media queries** para organizar os elementos e adaptar o layout a diferentes tamanhos de tela.

Como atividade prática, os alunos desenvolveram algumas seções do **Portal Terra**. A proposta está relacionada ao projeto de portal de notícias que vem sendo trabalhado em sala e tem como objetivo reforçar a construção da estrutura em HTML e a organização visual utilizando CSS e Flexbox.

Para os alunos que ainda possuem dúvidas sobre os conceitos apresentados ou sobre como desenvolver a estrutura em HTML e a estilização em CSS, está disponível o seguinte repositório de referência:

* [RCI Portal Terra](https://github.com/ifc-dev-web2/rci-portal-terra)

O repositório deve ser utilizado como material de consulta e apoio para a compreensão da atividade.

Também conversamos sobre a importância da **organização e da padronização do código**. Foram apresentadas ferramentas e extensões que ajudam a manter o projeto organizado, facilitando tanto o trabalho individual quanto o desenvolvimento colaborativo.

Entre as ferramentas abordadas, destacam-se:

* **Prettier:** responsável pela formatação automática e padronizada do código;
* **Linter:** responsável por identificar possíveis problemas e garantir que determinadas regras de código sejam respeitadas;
* **extensões do Visual Studio Code:** utilizadas para auxiliar na escrita, leitura e organização do projeto.

Além disso, conhecemos o recurso de **templates do GitHub** e vimos como ele pode agilizar a criação de novos repositórios, fornecendo uma estrutura inicial com arquivos, pastas e configurações previamente definidos.

Na parte de CSS, estudamos conceitos relacionados aos seletores e às regras utilizadas pelo navegador para determinar quais estilos serão aplicados aos elementos. Entre os assuntos apresentados, estão:

* seletores CSS;
* classes;
* herança;
* especificidade;
* pseudoclasses;
* pseudoelementos;
* organização das regras de estilização.

### Conteúdos trabalhados

1. Configuração, organização e formatação do repositório;
2. utilização de um template como estrutura inicial dos projetos;
3. seletores, herança e especificidade no CSS;
4. pseudoclasses e pseudoelementos;
5. Flexbox;
6. media queries e responsividade;
7. prática de desenvolvimento baseada no Portal Terra.
