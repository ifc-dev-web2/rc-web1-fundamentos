# Documentação da página inicial do Portal de Notícias

Esta documentação apresenta a estrutura da página `index.html`, responsável por
exibir as publicações sobre Programação, Banco de Dados e Segurança de Redes.

O objetivo da página é aplicar os seguintes conteúdos:

- estrutura básica de um documento HTML;
- HTML semântico;
- navegação entre páginas;
- organização de notícias com `section` e `article`;
- imagens acompanhadas de legendas;
- representação semântica de datas;
- separação entre estilos globais e estilos específicos.

## Responsabilidade de cada arquivo CSS

| Arquivo | Responsabilidade |
|---|---|
| `reset.css` | Remove ou normaliza os estilos iniciais aplicados pelo navegador. |
| `global.css` | Define cabeçalho, menu, tipografia, cores e rodapé compartilhados pelas páginas. |
| `styles.css` | Define a apresentação exclusiva da página inicial, das publicações e das imagens. |

A ordem de carregamento deve partir do estilo mais geral para o mais específico:

```html
<link rel="stylesheet" href="./css/reset.css">
<link rel="stylesheet" href="./css/global.css">
<link rel="stylesheet" href="./css/styles.css">
```

## Cabeçalho principal e cabeçalhos dos artigos

O documento contém diferentes elementos `<header>`, mas eles possuem funções
distintas.

```text
│                                              │
```

O `<header>` não representa obrigatoriamente o topo de toda a página. Ele também
pode introduzir uma seção ou um artigo.

## Sketch de cada publicação

Cada notícia é um conteúdo independente representado pela tag `<article>`.

```text
section
└── article
    ┌──────────────────────────────────────────────┐
    │ header                                       │
    │ ├── p.categoria                              │
    │ ├── h3 - título                              │
    │ └── p.subtitulo                              │
    ├──────────────────────────────────────────────┤
    │ figure.imagem-publicacao                     │
    │ ├── img - imagem relacionada à notícia       │
    │ └── figcaption - legenda da imagem           │
    ├──────────────────────────────────────────────┤
    │ p - primeiro parágrafo                       │
    │ p - segundo parágrafo                        │
    ├──────────────────────────────────────────────┤

    │ └── p + time - data da publicação            │
```

## Função dos elementos HTML

| Elemento | Função na página |
|---|---|
| `<header>` | Introduz o portal ou apresenta o cabeçalho de uma notícia. |
| `<nav>` | Agrupa os links de navegação entre as páginas. |
| `<main>` | Contém o conteúdo principal e exclusivo da página. |
| `<section>` | Agrupa uma publicação dentro de uma seção temática. |
| `<article>` | Representa uma notícia independente e reutilizável. |
| `<figure>` | Agrupa a imagem e sua legenda. |
| `<figcaption>` | Oferece uma legenda relacionada à imagem. |
| `<strong>` | Indica que determinado conteúdo possui forte importância. |
| `<time>` | Representa uma data ou horário em formato legível por sistemas. |
| `<footer>` | Apresenta informações finais do artigo ou da página. |

| Classe | Elemento | Responsabilidade |
|---|---|---|
| `.categoria` | `<p>` | Identifica a área ou disciplina relacionada à publicação. |

## Como os seletores encontram os elementos

| Seletor | Elementos selecionados |
|---|---|
| `main` | O conteúdo principal do portal. |

| `section > header h3` | Um `h3` dentro de um `header` que fosse filho direto de `section`. Também não encontra elementos atualmente. |
| `main > section` | As seções que são filhas diretas de `main`. |
| `.imagem-publicacao` | Todo elemento que possui essa classe, neste caso, as tags `figure`. |
| `.imagem-publicacao img` | As imagens localizadas dentro de `.imagem-publicacao`. |

| `article` | Todos os artigos da página. |

## Atenção ao combinador de filho direto `>`

O HTML atual possui esta hierarquia:

```text
section
└── article
    └── header
        └── h3
```

Por isso, o seletor abaixo não funciona na estrutura atual:

```css
section > header {
    margin-bottom: 25px;
    text-align: center;
}
```

O símbolo `>` exige que `header` seja filho direto de `section`. Entretanto,
existe um `article` entre esses dois elementos.

Uma correção possível é:

```css
article > header {
    margin-bottom: 25px;
    text-align: center;
}

article > header h3 {
    color: #173b82;
    margin-top: 35px;
    margin-bottom: 35px;
    font-size: 32px;
}
```

Outra possibilidade seria utilizar `section header`, mas esse seletor é mais
amplo e seleciona qualquer `header` descendente da seção, independentemente do
nível em que ele esteja.

## Referência das propriedades CSS utilizadas

### Container principal

| Propriedade | Valor | Função |
|---|---:|---|
| `max-width` | `960px` | Limita a largura máxima do conteúdo principal. |
| `margin` | `30px auto` | Cria 30px acima e abaixo e centraliza o elemento horizontalmente. |
| `padding` | `0 20px` | Cria 20px de espaço interno nas laterais do conteúdo. |

Como `main` não possui `width`, seu valor inicial é `auto`. Ele ocupa o espaço
disponível até atingir o limite de `960px`.

### Seções e cabeçalhos

| Seletor | Propriedade | Valor | Função |
|---|---|---:|---|
| `main > section` | `margin` | `10px` | Cria distância externa em todos os lados da seção. |
| `section > header` | `margin-bottom` | `25px` | Criaria espaço abaixo do cabeçalho, mas o seletor não corresponde ao HTML atual. |
| `section > header` | `text-align` | `center` | Centralizaria os textos do cabeçalho, mas não corresponde ao HTML atual. |
| `section > header h3` | `color` | `#173b82` | Aplicaria azul ao título se o seletor encontrasse o elemento. |
| `section > header h3` | `margin-top` | `35px` | Criaria espaço acima do título. |
| `section > header h3` | `margin-bottom` | `35px` | Criaria espaço abaixo do título. |
| `section > header h3` | `font-size` | `32px` | Definiria o tamanho da fonte do título. |

### Figuras e imagens

| Seletor | Propriedade | Valor | Função |
|---|---|---:|---|
| `.imagem-publicacao` | `margin` | `20px 0` | Cria 20px acima e abaixo da figura e nenhuma margem lateral. |

| `.imagem-publicacao img` | `width` | `100%` | Faz a imagem ocupar toda a largura disponível na figura. |
| `.imagem-publicacao img` | `height` | `auto` | Preserva a proporção original da imagem. |

| `.imagem-publicacao figcaption` | `color` | `#666` | Define um cinza mais escuro para o texto. |
| `.imagem-publicacao figcaption` | `font-size` | `0.9em` | Define a fonte como 90% do tamanho herdado. |
| `.imagem-publicacao figcaption` | `padding` | `10px` | Cria espaço interno em todos os lados da legenda. |

## Sobreposição de regras nas imagens

A mesma imagem corresponde a dois seletores:

```css
.imagem-publicacao img {
    display: block;
    width: 100%;
    height: auto;
}

article img {
    width: 100%;
    margin: 15px 0;
}
```

As regras não se anulam. O navegador combina as propriedades dos dois blocos.
Assim, a imagem recebe `display`, `width`, `height` e também `margin`.

Como a própria `.imagem-publicacao` já possui `margin: 20px 0`, a imagem recebe
uma segunda margem vertical dentro da figura. Isso pode gerar mais espaço do que
o esperado.

Uma organização mais simples seria concentrar as regras em:

```css
.imagem-publicacao img {
    display: block;
    width: 100%;
    height: auto;
}
```

e remover o bloco genérico `article img`, caso não existam outras imagens dentro
do artigo que precisem dessa regra.

## Diferença entre os dois rodapés

A página utiliza rodapés em dois níveis:

```text
article
└── footer
    └── data e horário daquela publicação

body
└── footer.footer
    └── informações gerais do projeto
```

A classe `.footer` permite estilizar somente o rodapé principal sem alterar os
rodapés existentes dentro dos artigos.

Exemplo:

```css
.footer {
    padding: 1.5rem;
    text-align: center;
}

article footer {
    padding-top: 1rem;
    padding-bottom: 1.5rem;
    color: #666666;
    font-size: 0.875rem;
}
```

## Datas com a tag `time`

```html
<time datetime="2026-08-21T21:06">
    21 de agosto de 2026 às 21:06
</time>
```

O conteúdo entre as tags é apresentado para as pessoas. O atributo `datetime`
armazena a data em um formato padronizado que pode ser interpretado pelo
navegador, mecanismos de busca e tecnologias assistivas.

## A importância do atributo `alt`

O texto alternativo deve descrever a imagem específica daquela publicação.
Atualmente, todas as imagens utilizam `alt="estrada com montanhas"`, mas apenas a
primeira imagem parece corresponder a essa descrição.

Exemplos mais adequados:

```html
<img
    src="./img/estrada.avif"
    alt="Estrada atravessando uma região cercada por montanhas"
>

<img
    src="./img/banco-de-dados.avif"
    alt="Representação de um banco de dados e suas conexões"
>

<img
    src="./img/seguranca-de-redes.jpeg"
    alt="Representação da proteção de uma rede de computadores"
>
```
